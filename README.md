Proyecto Calculadora
menu.py es la parte menú archivo principal donde se interactúa con el usuario para realizar las operaciones.

calculadora.py es donde se realizan las operaciones básicas (suma,resta,etc.).

CalcEsp.py es donde se realizan operaciones especiales (raíz,IVA,etc).

Calctrig.py se realizan las operaciones trigonométricas (seno,coseno,etc).

Nota:Los tres últimos archivos mencionados son importados al menú.py para su uso de operacion requerida por el usuario.
